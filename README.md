# shanghai-trip

แผนเที่ยวเซี่ยงไฮ้ 1–4 ธ.ค. 2026 · เว็บสำหรับเปิดในมือถือ

**เปิดใช้งาน:** https://auchareetwork-arch.github.io/shanghai-trip/

- 🏠 ภาพรวม: นับถอยหลัง, สิ่งที่ต้องทำถัดไป, อากาศ, เวลาละหมาด
- 🎒 เตรียมตัว: เช็คลิสต์ของกลุ่มและของที่ต้องพา (เก็บในมือถือแต่ละเครื่อง)
- 🗺️ แผนรายวัน: ไทม์ไลน์ 4 วัน พร้อมลิงก์ Google Maps / Amap
- 📇 ข้อมูล: ที่อยู่โรงแรมภาษาจีนไว้โชว์คนขับ, ไฟลท์, แปลงเงิน, ประโยคจีน, แอพ, เบอร์ฉุกเฉิน

เอกสารการจองและข้อมูลส่วนตัวไม่ได้อยู่ใน repo นี้
